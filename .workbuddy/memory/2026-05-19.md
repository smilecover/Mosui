# 2026-05-19 工作记录

## 修复 HomePage 不显示问题

**文件**：`Mosuiapp/Main.qml`

**根因**：`MosRouter.push(data.source)` 传入的是 JS 字符串 `'./Controls/HomePage.qml'`，C++ 侧转为 `QUrl` 时没有 base URL 上下文，变成无 scheme 的相对 URL，`Loader.source` 无法定位文件，页面不渲染。

**修复**：
1. `onClickMenu` 里改为 `galleryRouter.push(Qt.resolvedUrl(data.source))` — 解析为绝对 URL。
2. `SettingsPage` push 也同步改为 `Qt.resolvedUrl('./Controls/SettingsPage.qml')`。
3. 新增 `Component.onCompleted` 手动 push 初始 HomePage，防止 `defaultSelectedKeys` 时序竞争导致初始页不加载。

**经验**：在 QML 中从 JS 对象取出的路径字符串传给 C++ `QUrl` 参数时，务必用 `Qt.resolvedUrl()` 包裹，避免相对路径 URL 解析失败。
