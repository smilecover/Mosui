## Rain on Glass 着色器移植（两版迭代）

### 第一版：纯 GLSL 程序化方案
- 城市背景和雨滴全部在着色器中程序化生成
- 问题：效果与原版差距大——雨滴没有物理运动感、城市背景细节不足

### 第二版：Canvas2D 背景 + GLSL 雨滴折射（中间版本，效果仍不理想）
- 城市背景用 Canvas2D 生成，但雨滴仍用 GLSL 程序化网格——没有物理运动感

### 第三版：完整 Canvas2D 物理引擎移植（当前版本）
- 完整移植原版 `rain-on-glass.html` 的 JS 物理引擎到 QML Canvas2D
- 核心架构与原版完全一致：Canvas2D 雨滴物理 → 水贴图 → ShaderEffect 折射
- **重要修复**：QML Canvas `drawImage()` 不接受 Canvas 对象作为源（只接受 Image/URL）
  - 预渲染 stamp 架构改为直接 `putImageData` 像素合成
  - `_drawDrop()` 从 drawImage(stamp) 改为逐像素 alpha 合成（_dropAlphaData + _dropColorData + depthIdx screen-blend）
  - `_clearDroplets()` 从 drawImage(clearStamp) 改为 destination-out + 径向渐变填充
  - dropletsCanvas → rdCanvas 复制从 drawImage(canvas) 改为 getImageData/putImageData
- 构建通过，无错误

## Fractal_Land 着色器移植

- 从 ShaderToy 移植 Fractal Land 到 Qt 6 ShaderEffect
- **路径修复**：`qt_add_shaders(PREFIX "/")` 输出 `.qsb` 到 `:/shaders/...`，QML 需用 `qrc:/shaders/...` 绝对路径
- **uniform 拆离**：自定义 uniform（iResolution/iTime/iMouse）必须从 `buf` block 中拆出为独立声明，Qt 6 的 `buf` 只认 `qt_Matrix` + `qt_Opacity`
- **sampler binding**：binding 0 固定给 uniform buffer，sampler 从 binding 1 开始
- **fragCoord 传递**：vertex shader 中用 `qt_MultiTexCoord0 * vec2(width, height)` 生成像素坐标（利用 GLSL `width`/`height` 内建变量，避免额外的 uniform 传递）
- **纹理依赖移除**：禁用 NYAN cat 和 iChannel0/1 纹理采样，避免 null texture 导致黑屏
- **opacity**：ShaderEffect 上不要设 opacity: 0.5，会让画面变暗
